
# Food Platform - Git Branching Strategy

## Project Overview
Food Platform is a React and Vite based web application.

## Team Structure

Developer 1: Login and Authentication
Developer 2: Food Menu
Developer 3: Order Management

## Branching Strategy

### Main Branch
- Contains stable project code.
- Only tested features are merged.

### Feature Branches

1. feature/login
   - Login and authentication development.

2. feature/menu
   - Food menu development.

3. feature/orders
   - Order management development.

## Development Workflow

1. Create feature branches from main.
2. Developers work independently.
3. Commit changes with meaningful messages.
4. Merge completed features into main.
5. Resolve merge conflicts before completing merges.
6. Keep main stable and updated.
